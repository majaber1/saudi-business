FeasibilityOS AI

AI Operating System for Investment Decisions

V1.1 FastAPI Saudi Funding Programs

FeasibilityOS AI turns a business idea into an investment-ready feasibility study: a real financial engine (ROI, NPV, IRR, sensitivity analysis) paired with an explainable matcher against Saudi government funding programs (NTDP, Monsha'at, CODE, SVC, Kafalah, RDIA).

Live API Docs Source on GitHub

What's live in V1.1

  • POST /financial/evaluate — ROI, payback, NPV, IRR, feasibility verdict
  • POST /financial/sensitivity — revenue-shock sensitivity analysis
  • POST /funding/match — scored, explainable match against 6 Saudi programs
  • POST /projects — project creation and workflow status
