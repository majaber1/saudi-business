# Inovasys brand kit

## Concept

**Inovasys** = innovation + systems.

The mark shows three ascending bars (systems growing) ending in a forward tip
(innovation advancing). It reads as progress, structure, and forward motion
without relying on a literal letterform.

## Colors

| Role | Name | Hex | Usage |
|---|---|---|---|
| Primary | Deep teal | `#0F766E` | Mark bars, brand actions |
| Accent | Copper | `#C2673A` | Innovation tip only |
| Ink | Slate 900 | `#0F172A` | Wordmark on light |
| Light mark | Teal bright | `#2DD4BF` | Mark on dark backgrounds |
| Light accent | Soft copper | `#E8A87C` | Tip on dark backgrounds |
| White | — | `#FFFFFF` | Wordmark on dark |

Avoid purple gradients and glow effects. Keep the copper accent sparse.

## Typography

- Wordmark: **Montserrat Bold** (fallbacks: Avenir Next, Segoe UI, Helvetica)
- Tracking: slightly tight (`letter-spacing: -0.03em`)
- Do not stretch, outline, or add drop shadows to the wordmark

## Assets

| File | Use |
|---|---|
| `logo-horizontal.svg` | Primary lockup (icon + wordmark) on light |
| `logo-light.svg` | Lockup on dark / teal backgrounds |
| `logo-icon.svg` | App icon, avatar, square placements |
| `logo-icon-mono.svg` | Single-color mark (`currentColor`) |
| `favicon.svg` | Browser favicon (16–32px) |
| `inovasys-logo-primary.png` | Raster preview / presentations |
| `inovasys-logo-icon.png` | Raster icon preview |
| `inovasys-logo-dark-bg.png` | Dark-background raster preview |

## Clear space

Keep empty space around the mark equal to at least **¼ of the icon width** on
all sides. Do not place the logo inside crowded card chrome or over busy photos
without a solid backdrop.

## Minimum sizes

- Icon alone: 24px
- Horizontal lockup: 120px wide
- Favicon: 16px (use `favicon.svg`)
